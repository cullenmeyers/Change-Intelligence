Shopify public apps must use expiring offline access tokens by 2027

Reviewed August 10, 2026Evidence confidence: Official Shopify developer changelogPrimary domain: Authentication / Admin API access
Current decisionPublic Shopify apps that still make Admin API requests with non-expiring offline access tokens should migrate token exchange and storage before January 1, 2027.

What changed?

Starting January 1, 2027, Shopify public apps must use expiring offline access tokens when calling the Admin API. After that date, public apps still using non-expiring tokens will receive authentication errors.

Who is affected?

Affected apps are public apps making Admin API requests using non-expiring offline access tokens, including apps created before April 1, 2026. Shopify lists custom apps and merchant-created apps in the Dev Dashboard or admin as unaffected by this specific change.

What can break?

  • Background jobs, syncs, webhooks, and Admin API calls can fail with authentication errors after the deadline.
  • Apps may appear installed but be unable to perform server-side Admin API work.
  • Token storage and refresh logic may need changes even if merchants do not reinstall.

Smallest safe migration

  1. Identify whether your app is public and still stores non-expiring offline tokens.
  2. Implement the expiring offline token exchange path.
  3. Update token storage so the app can rotate tokens safely.
  4. Test background Admin API jobs and webhook-triggered flows with the new token model.
  5. Roll out before January 1, 2027.
